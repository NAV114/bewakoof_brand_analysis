# Bewakoof Brand Decline — Data Analysis

A data analyst case study examining why one of India's most recognisable 
D2C fashion brands stalled after a ₹200 Cr acquisition.

## What this project covers
- P&L analysis (FY20–FY25)
- Expense ratio and unit economics
- Competitor benchmarking vs Snitch, The Bear House, Urbanic
- Google Trends brand sentiment analysis
- Root cause analysis and strategic recommendations

## Tools used
Python, pandas, matplotlib, seaborn, pytrends, Jupyter Notebook

## Key finding
Bewakoof spent ₹1.65 to earn every ₹1 of revenue in FY24. 
Bootstrapped competitor Snitch — founded 8 years later with zero 
funding — already earns ₹280 Cr vs Bewakoof's ₹173 Cr.
